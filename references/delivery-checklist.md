# Final delivery review

Review the generated **PDF**, not only its Markdown or Word source.

## Academic review

- Every mandatory question and output is answered; each scored criterion has visible evidence. A suggested framework is used only when it helps the case.
- The case is real and anonymized at the right level. Assertions, numbers, formulas, denominators, time windows, and commercial assumptions can be traced. Claims of measured performance are supported by actual results; proposals are labeled as such.
- Each significant outside claim has an in-text citation that supports that claim; every cited work has a matching reference entry. Links/DOIs, author names, dates, titles and publication details were checked against the source. No invented references.
- The requested language and tone are met. A translated English version is reviewed as its own paper, including terminology, logic and word count.

## Submission review

- The current assignment PDF, rubric, any LMS submission notice, and relevant lectures were checked; unresolved specification conflicts are closed or stated to the user.
- Filename exactly follows the official rule when one exists; otherwise it matches the recorded working convention. Course title/code and student name agree across the requirement matrix, source, PDF first page, repeated headers/footers and file metadata where used. Search the exported PDF for stale course codes.
- Word count is taken from the final PDF under the required inclusion rule. Also inspect the alternative pre-references count if the rule is ambiguous; abstract/cover can push an apparently compliant body over the cap. Check per-question ranges when specified.
- PDF opens, has expected page order, legible tables/citations, no clipped text or blank/scanned pages, and extractable text. Review the first and last pages plus every page containing tables or unusual layout visually.
- A separate reviewer, when used, compares the final file to the official task and rubric. Record the findings and fixes; do not report a review that was not performed.
